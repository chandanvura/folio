# Sri Chandan Vura — Engineering Folio

Interactive data-visualization portfolio, engineering track showcase, and career dossier for **Sri Chandan Vura** (Backend, Platform & Reliability Engineering).

- **Live GitHub Pages URL**: https://chandanvura.github.io/folio/
- **Repository**: https://github.com/chandanvura/folio
- **GitHub Profile**: https://github.com/chandanvura
- **LinkedIn**: https://linkedin.com/in/chandanvura

## Highlights
- **10 Interactive Sections & Charts**: 52-repo unit matrix, 100% stack bar & cross-highlighting track table, 2024 vs 2026 dumbbell progression, role-track rotated-numeral switcher (`Java Backend`, `Platform & DevOps`, `Reliability & SRE`, `Full-Stack API`), scroll-scrubbed career timeline (`2020–2026`), scrollytelling repository columns, 10×5 skill heatmap, reliability waffle & Likert bars, P99 latency scatter with live OLS regression, and a searchable 16-entry dossier with CSV export.
- **Dark & Light Themes**: Header quick-toggle (`D` shortcut), footer toggle, **Night Edition (Dark)**, **Obsidian Press (Dark)**, and 6 editorial light themes with WCAG 2.2 AA contrast tokens.
- **Resume & Source Links**: Direct PDF resume download and verified GitHub/portfolio project links.

## Local Development
```bash
npm install
npm run dev
```

## Production Build & GitHub Pages Deployment
Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds `./dist` with Vite (`npm run build`) and deploys automatically to GitHub Pages.
